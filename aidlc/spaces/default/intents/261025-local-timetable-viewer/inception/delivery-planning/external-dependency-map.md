# External Dependency Map

Nothing outside this session holds the Bolt. The day's MCA is on this machine. Docker is local. There is no hosted API, no other team, and no approval window.

## Dependencies

| Item | Owner | Which Bolt | If it slips |
| --- | --- | --- | --- |
| That day's MCA file | This machine | Bolt 1 | The empty screen stays empty. The load button has nothing to start. |
| Docker on this machine | This machine | Bolt 1 | The three containers do not start. |

DBeaver is optional. It opens the host path of the SQLite file. It does not block the Bolt.
